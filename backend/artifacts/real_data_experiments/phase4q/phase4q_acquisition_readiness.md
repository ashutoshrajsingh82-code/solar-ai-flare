## 3. Step-by-Step Operator Standard Operating Procedure (SOP)

To download additional observation dates from PRADAN, the authorized operator must execute the following protocol:

### Step 1: Portal Navigation and Interactive Authentication
1. Open a web browser and navigate to the official ISSDC PRADAN URL:  
   `https://pradan1.issdc.gov.in/al1/`
2. Click **Login** and authenticate through the ISRO Keycloak Single Sign-On portal using valid institutional credentials.

### Step 2: Observation Search & Filter Selection
1. Navigate to **Data Search & Download**.
2. Set search parameters:
   - **Mission:** `Aditya-L1`
   - **Instrument:** `SoLEXS`
   - **Data Level:** `Level-1`
   - **Product Type:** `Lightcurves (lc)` and `Spectrograms (pi)`
   - **Detector:** `SDD2` (and `SDD1` if flagged operational)
3. Target Observation Dates (Prioritized Candidate Windows):
   - **Primary High-Activity Target:** `2024-05-08` to `2024-05-15` (Solar Cycle 25 historic X-class flare cluster).
   - **Continuous Regular Target:** `2024-07-01` to `2024-09-30` (UTC-aligned Level-1 release).
   - **Post-Cohort Extension:** `2026-02-06` to `2026-02-28`.

### Step 3: Shopping Cart & Download Script Generation
1. Select target products and click **Add to Cart**.
2. Proceed to **Cart** -> Click **Download Script**.
3. PRADAN will generate an export script (e.g., `solexs_<timestamp>.py`) configured with an active session token valid for the download duration.

### Step 4: Local Workstation Execution
1. Save the generated script into `C:\Users\ASHUTOSH\Downloads\`.
2. Open PowerShell or Command Prompt and execute:
   ```powershell
   python C:\Users\ASHUTOSH\Downloads\solexs_<timestamp>.py
   ```
3. Allow downloads to complete until the outer zip archives (e.g., `solexs_<timestamp>.zip`) are fully written to disk.

### Step 5: Automated Ingestion & Provenance Verification
1. Run the Phase 4Q operator acquisition verification tool:
   ```powershell
   cd C:\Users\ASHUTOSH\Downloads\solar-ai-flare-main\solar-ai-flare-main\backend
   python scripts/operator_acquisition_helper.py --archives C:\Users\ASHUTOSH\Downloads\solexs_<timestamp>.zip
   ```
2. Run the Phase 4Q dataset indexer to regenerate the expanded manifest:
   ```powershell
   python scripts/index_real_observations.py --manifest-prefix phase4q_expanded_dataset_manifest --additional-archives C:\Users\ASHUTOSH\Downloads\solexs_<timestamp>.zip
   ```
