## 1. Executive Summary

This report documents the architectural investigation, security audit, and empirical live testing of the ISRO Indian Space Science Data Centre (ISSDC) PRADAN portal acquisition pipeline. The objective was to evaluate automated downloading of genuine Aditya-L1 SoLEXS and HEL1OS Level-1 observational data beyond the existing 6-day epoch (2026-01-31 to 2026-02-05).

### Key Technical Findings
1. **Endpoint Access Architecture:** All Level-1 observational data files are served through a protected gateway:  
   `https://pradan1.issdc.gov.in/al1/protected/downloadData/{mission}/{instrument}/{path}`
2. **Authentication Barrier:** Access to the `/protected/` path hierarchy is strictly gated behind an OpenID Connect (OIDC) / OAuth2 authentication flow managed by the ISRO Keycloak Identity Provider (`idp.issdc.gov.in`).
3. **Session Expiration:** Empirical endpoint probing confirms that past session tokens embedded in historic automated scripts (`solexs_2026Oct23T173715534.py`) are expired. Any direct HTTP request without a valid interactive browser session cookie returns an HTTP 302 Redirect to the Keycloak authentication login screen.
4. **Acquisition Determination:** Under Non-negotiable Requirement 3 ("Do not claim data has been acquired unless actual execution results establish it") and Non-negotiable Requirement 10 ("Honest assessment of barriers"), the phase status is conclusively determined as:  
   **`INDEXING_COMPLETE_ACQUISITION_BLOCKED`**.
5. **Security Isolation:** No interactive user credentials, long-lived refresh tokens, or personal ISSDC passwords were fabricated, mocked, or committed to source control.

## 3. Empirical Live Endpoint Probing Results

A direct live network probe was executed against the PRADAN download endpoint to test whether public or unauthenticated downloads are permitted:

```bash
# Probing PRADAN protected download endpoint
curl -I -s "https://pradan1.issdc.gov.in/al1/protected/downloadData/al1/solexs/level1/..."
```

### Response Headers
```http
HTTP/1.1 302 Found
Date: Sun, 25 Oct 2026 19:12:45 GMT
Server: Apache/2.4.41 (Ubuntu)
Location: https://idp.issdc.gov.in/auth/realms/issdc/protocol/openid-connect/auth?client_id=al1-client&redirect_uri=https%3A%2F%2Fpradan1.issdc.gov.in%2Fal1%2Flogin%2Foauth2%2Fcode%2Fissdc&response_type=code&scope=openid&state=...
Set-Cookie: SESSION=...; Path=/al1; HttpOnly; SameSite=Lax
Content-Length: 0
Connection: close
```

### Interpretation
- **HTTP Status:** 302 (Redirect).
- **Target URL:** ISRO Keycloak Single Sign-On login portal.
- **Root Cause:** Absence of valid authenticated session cookie. The server cleanly refused payload transfer and redirected the client to the interactive login page.
- **Scientific Conclusion:** Autonomous, unauthenticated machine-to-machine downloading cannot proceed without human authentication or an authorized programmatic API token provided by ISRO/ISSDC.

## 5. Standard Operating Procedure (SOP) for Authorized Data Acquisition

To expand the dataset beyond the 6-day epoch, an authorized human operator must follow this standard operating procedure:

### Step 1: Interactive Authentication
1. Navigate to the ISSDC PRADAN portal: `https://pradan1.issdc.gov.in/al1/`
2. Log in with authorized ISRO ISSDC user credentials.
3. Navigate to **Data Search & Download** -> Select **Mission: Aditya-L1** -> Select **Instrument: SoLEXS**.

### Step 2: Date Selection & Shopping Cart
1. Select the desired observation dates (e.g., February 6–28, 2024, or the major X-class flare epoch of May 2024).
2. Filter for:
   - **Data Level:** Level-1 (`lev1`)
   - **Data Product:** Lightcurves (`lc`) and Spectrograms (`pi`)
   - **Detector:** SDD2 (and SDD1 if operational)
3. Add products to Cart and proceed to Download.

### Step 3: Script Export & Local Execution
1. ISSDC provides a generated Python download script with a fresh, active session token (e.g., `solexs_<timestamp>.py`).
2. Download the script to the workstation and execute within the active session window:
   ```bash
   python solexs_<timestamp>.py
   ```
3. Verify download integrity against ISSDC MD5/SHA-256 checksums.

### Step 4: Indexing & Ingestion
1. Place downloaded zip archives into `E:\SolarFlareData` or `C:\Users\ASHUTOSH\Downloads\`.
2. Run the Phase 4P scalable dataset indexer:
   ```bash
   cd C:\Users\ASHUTOSH\Downloads\solar-ai-flare-main\solar-ai-flare-main\backend
   python scripts/index_real_observations.py --solexs-archive <path_to_new_archive>
   ```
3. The indexer will automatically validate FITS headers, extract monotonic contiguous segments, audit duty cycles, and generate updated JSON/CSV manifests.
